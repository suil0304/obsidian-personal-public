의견이 정말 갈리는 것 같지는 않고,
이제는 소수가 되어 버린 이야기처럼 들리기 쉽다.

내가 안다.
나도 이에 대해서 반 이상은 옳다고 생각한다.

*"반 이상 옳다?"*

무조건은 아니라는 소리인 거지.

그것을 아는가?
기업은 이미 AI를 사용하고 있다.
사용 빈도는 거의 100%.
이미 이 시대를 꺾을 수 없다.
말로는 무슨 러다이트 운동을 해야 한다 하더라도 전혀 꺾을 수 없다.
지금의 흐름이다.

어느 정도 강력한 착각을 하는 듯 싶다.
AI가 무조건적으로 나쁜 것은 전혀 아니다.

설령 인공지능 환각 현상으로 전혀 다른 답을 내놓더라도,
AI가 무조건적으로 나쁜 것은 전혀 아니다.

우리가 길러야 할 것은 이제 외우는 것이 아니다.
이해하는 사람이면 좋겠지만,
여러분들은 이것을 보통 외우면서 살지 않는가?

자랑하는 이야기는 전혀 아니지만,
나는 웬만해서는 거의 무조건적으로 이해를 하고 넘어가는 사람이다.
```Java
public class Main {
	public static void main(String[] args) {
		System.out.println("Hello, world!");
	}
}
```

여기에서 "System이 어떻고 out이 어떻게 해서 이렇게 된다."
라는 빠른 구조 분석이 아닌 외우기의 답이 나오는 것이 대부분의 현실이다.

이를 더 잘 이해하기 위해 내 손으로 직접 프로그래밍을-
헛소리하지 않는가 다시 한 번 생각해보자.
대부분의 경우 자기 자신을 제대로 살펴보지 않고 말하는 망상이며 거짓이다.

그렇다면 나는 어째서 반 정도 이 이야기를 옳다고 하는가?

말 그대로다.

정확히 말하자.
나는 AI를 사용하는 것 자체를 부정하지 않는다.
전혀 부정하지 않는다.

AI를 잘못 사용하는 것에 대하여 부정하고 있을 뿐이다.
말장난하는 것처럼 들리는가?

당신은 아마 나중에 IT 기업 면접을 봐야만 할 사람일 것이다.
지금까지 해온 모든 프로젝트를 AI로 돌리고는
"저 이런 것들 해왔어요!"
라 말했을 때 통과가 될 것이라 생각하나?

아니다.

모든 것을 AI에게 맡기려 생각하지 마라.
동시에 AI를 무조건적으로 부정하려 하지 마라.

코딩에 대한 공부는 필수다.
컴퓨터 과학에 대한 공부도 무조건적으로 필수다.

이를 착각하려 들지 마라.
