언어를 많이 배운다고 하여 그것이 과연 효과적일까?
한 번 고찰해보자.

지금으로 할 줄 아는 언어가 대략
- C
- C++ (문법만)
- Java (문법만)
- JavaScript
- TypeScript
- Python
- Haxe
- Lua
- SQL
- HTML
- CSS
정도이다.

프로그래밍 언어인가 아닌가는 고려하지 않았으니 그 부분에 대한 태클은 멈춰 주기를.

그렇다면 이런 나는 이 질문에 대하여 무슨 대답을 할 수 있는가?

> **충분히 효과적이었다.**

그것이 넓고 얇게가 아닌 깊고 그 언어의 철학을 충분히 이해하고 있다면 말이다.

한 예시를 들어보자.

당신은 이제 막 Python과 Java, C, C++, C#, Pascal, Haxe, JavaScript를 동시에 Hello, world!까지 작성할 수 있는 사람이 되었다.
당신은 자기 자신을 코딩 잘 한다 말할 수 있는가?
아니지 않은가?

반면 Python의 깊은 철학,
Pythonic을 심도 깊게 이해하며, 최소한 클래스의 매직 메서드를 건드리는 수준까지 간 사용자가 다른 2개의 언어를 이와 비슷한 수준으로 이해하고 있다고 하자.
우리는 이 사람을 객관적으로 당신과 비교할 수 있다.
대부분의 사람은 이 사용자를 더 잘 하는 사람이라 볼 것이다.

특이하지 않은가?

우리는 기본적으로 언어를 잘 알고 있는 이에 대해 "저 인간은 코딩 잘 하겠다."라 고정 관념이 자리 잡고 있다.
실상은 다르다는 이야기이다.

그 언어를 잘 이해하는 것이 더 중요하다.
그리고 된다면 그 가지를 넓히는 것도 좋겠지.

이거자랑하는글아니에요
