쉽게 말해서 사용자가 활동(웹사이트 이용으로 API에 요청을 보내는 등)하는 경우 만료 시간을 다시 갱신하는 것입니다

근데 사용자가 24시간 365일 컴퓨터를 꺼놓지도 않고 30분마다 한 번씩 계속 요청 보내고 있으면 만료가 안 되잖아요
그래서 절대 만료 기간을 추가로 두는 것이 좋습니다

[[JWT|JWT]]에서도 가능하구요
# Refresh Token Rotation
Access Token이 만료되면 Refresh Token으로 재발급 받으면서 Refresh Token도 같이 재발급하는 것입니다

# Token Renewal
특정 조건을 만족하면 새로운 JWT를 발급하는 방식이구요
