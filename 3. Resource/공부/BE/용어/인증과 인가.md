# 인증 (Authentication)
신원을 확인하는 과정입니다
여러분들 신분증으로 인증하잖아요
그런 느낌인 거죠

# 인가 (Authorization)
어떤 개체가 해당 리소스에 접근할 권한이 있는가를 검증하는 것입니다
인증과는 별개라는 거죠

인증을 받지 않고 수정될 수 있는 역할에 관리자 권한을 준 다음 여러분들에게 부여하면
여러분들은 채널을 수정할 수 있는 인가를 통과하고 수정할 수 있는 것입니다

# 흐름이라 하자면
인증하고 인가로 흘러갈 수는 있어요
반대가 거의 없을 뿐이지
아예 없다고 하기에는 본 것이 없어서 단언은 못 하겠네요

신분증 보고 이를 바탕으로 무언가에 대한 권한을 검사하는 것이 인증 후 인가 처리라 볼 수 있겠구요
