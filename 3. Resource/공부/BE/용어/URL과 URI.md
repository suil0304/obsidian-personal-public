# URL (Uniform Resource Locator)
여기까지만 포함된다 보시면 됩니다
| "https://youtube.com"

위치를 나타내고 싶은 것이지
정확하게 식별하라고 하는 건 아니잖아요

# URI (Uniform Resource Identifier)
예를 들자면 이것 전체입니다
| "https://youtube.com/channel/"

여기에 추가로 Query Arguments 등도 포함되구요
Path Variable도 포함됩니다
