대충 JS의 기본 타입은 다 있습니다
TS의 any와 unknown도 지원하구요
이 값이 파일인지 검증하는 함수도 있습니다

당연하지만 모든 스키마 구현 함수를 전부 적어두지는 않았으니 알아두고 계시구요

# JS 원시 자료형
딱히 설명이 필요할 것 같지는 않아서 이렇게만 적어두다

```TypeScript
Zod.string();
Zod.number();
Zod.boolean();
Zod.bigint();
Zod.symbol();
Zod.null();
Zod.undefined();
```

지금 보니 null과 undefined 스키마 때문에 기본적으로 이딴 괴상한 export를 작성했던 것 같기도 하구요
![[zod#^debf56]]

당연하지만 JS는 int와 float를 number로 뭉갰기 때문에
int만 받고 싶다면 이렇게 하셔야 하구요

```TypeScript
Zod.number().int();
```

# JS+
```TypeScript
Zod.object();
// whitelist만 받고 싶을 때: strictObject
// 추가 값이 들어와도 상관 없을 때: looseObject
Zod.function();
Zod.array();
Zod.map();
Zod.set(); // 집합 맞아요 JS Set
Zod.date();
```

# TS
```TypeScript
Zod.any();
Zod.unknown();
Zod.never();
Zod.union(); // A | B
Zod.intersection(); // A & B
Zod.record(); // Record<K, V>
Zod.literal();
Zod.enum();
```

# TS+
```TypeScript
Zod.tuple(); // 쉽게 설명하자면 다음과 같습니다: [string, string]
```

# 구현됨
```TypeScript
Zod.file();
```

# 특수
```TypeScript
Zod.nullable();
Zod.optional(); // undefined 가능
Zod.nullish(); // nullable & optional
Zod.instanceof();
Zod.custom(); // 커스텀 스키마이구요 (data:unknown) => unknown을 받습니다
Zod.lazy(); // lazy하게 스키마를 뽑습니다
Zod.json(); // JSON으로 표현 가능한지를 검증합니다
```
