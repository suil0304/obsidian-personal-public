배경 지식부터 쌓고 갑시다

UNIX 계열 운영체제에는 cron이라 불리우는 명령어가 있습니다
시간 기반 작업 스케줄러구요

이런 느낌으로 작업 스케줄링을 할 수 있도록 지원해주는 라이브러리가 바로 node-cron입니다

대충 이런 방식으로 사용합니다
```TypeScript
import cron from "node-cron";

cron.schedule("* * * * *", () => {
	console.log("test");
});
```

여기에서 앞의 `"* * * * *"`는 cron expression입니다

# cron expression
대충 `"* * * * *"`에서 가장 앞의 자리부터 순서대로 `"분 시 일 월 요일`이라 생각하시면 됩니다

`"* * * * *"`라고만 박아두시면 매 분에 실행해주세요라 하는 것이구요

`"*/5 * * * *"`와 같이 /를 두고 저렇게 사용하시면 step이 되는 것 같습니다

사실 원래 이거 6개 있는데
6개까지 적으면 맨 앞이 초거든요?
`"초 분 시 일 월 요일"`

근데 5개만 적으면 초가 생략되어 저렇게 된다네요

범위 표시는 -으로 하시면 되구요
