현재 NestJS는 [[데코레이터#parameter|Parameter Decorator]]만을 빠르게 만들 수 있도록 지원하고 있습니다

나머지도 가능하기는 하겠다만
꽤 힘들 것이구요

# createParamDecorator
```TypeScript
export type ParamDecoratorEnhancer = ParameterDecorator;
/**
 * Defines route param decorator
 *
 * @param factory
 * @param enhancers
 *
 * @publicApi
 */
export declare function createParamDecorator<
	FactoryData = any,
	FactoryOutput = any
>(
	factory: CustomParamFactory<FactoryData, FactoryOutput>,
	enhancers?: ParamDecoratorEnhancer[]
): (
	...dataOrPipes: (
		Type<PipeTransform>
		| PipeTransform
		| FactoryData
		| ParameterDecoratorOptions
	)[]
) => ParameterDecorator;
```

이렇게들 받는데
factory에 집중해볼까요

```TypeScript
/**
 * @publicApi
 */
export type CustomParamFactory<TData = any, TOutput = any> = (data: TData, context: ExecutionContext) => TOutput;
```

간단합니다
data에는 나중에 @Test("test") 등으로 호출했을 때 들어오는 값입니다
context는 [[Guard#ExecutionContext|실행 문맥]] 그것이구요

enhancers는 먼저 제 Parameter Decorator를 먼저 적용시키고 추가로 적용시킬 것들입니다
알만 하잖아요
