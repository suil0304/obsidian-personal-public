NestJS는 기본적으로 예외 처리 레이어를 두고 있습니다
우리가 작성할 때 try-catch로 잡지 않은 것들이 기본적으로 여기에서 잡히는 것이구요

그러면서 Controller 기준으로는 JSON 형태로 예외가 변환되어 반환되는데
이것도 기본 예외 필터의 처리입니다

뭐
HttpException이라는 공통 예외를 상속 받지 않지 않았거나
애초에 HttpException이 아닌 경우 등은 마찬가지로 기본 예외 필터가 500 Internal Server Error를 반환합니다

그러니까 Controller 내부에서 갑자기 throw new Error를 해도 InternalServerErrorException이 나가는 것이구요

# 언제 실행되는가?
당연히 에러가 터졌을 때입니다
별 것 없어요

# 실행 순서
잡을 수 있는 친구가 먼저 잡습니다

전역이 먼저 안 잡아요

# Catch
*class decorator*

어떤 예외들을 잡을 것인지 여기에서 명시할 수 있습니다

```TypeScript
import { ArgumentsHost, Catch, ExceptionFilter } from "@nestjs/common";

@Catch()
class TestFilter implements ExceptionFilter {
	catch(error:Error, host:ArgumentsHost) {}
}
```

기본적으로는 비워두었을 때 모든 에러를 받습니다

Catch에 어떤 에러를 채워 넣으면 이를 상속하는 에러들도 받게 만들 수 있구요

# ExceptionFilter
```TypeScript
import { ArgumentsHost } from '../features/arguments-host.interface.js';
/**
 * Interface describing implementation of an exception filter.
 *
 * @see [Exception Filters](https://docs.nestjs.com/exception-filters)
 *
 * @publicApi
 */
export interface ExceptionFilter<T = any> {
    /**
     * Method to implement a custom exception filter.
     *
     * @param exception the class of the exception being handled
     * @param host used to access an array of arguments for
     * the in-flight request
     */
    catch(exception: T, host: ArgumentsHost): any;
}
```

이것을 구현해서 ExceptionFilter를 구현하시면 됩니다
간단하죠

catch는 기본적으로 host.switchToHttp().getResponse에서 받은 응답 객체의 응답을 변환시키는 것이 기본 예제로 나와 있습니다
Filter에서 다시 throw해버리면 NestJS의 에러 처리 레이어에서 벗어나 자칫 잘못하면 런타임 수준의 에러를 터트릴 수도 있으니 조심하세요

# BaseExceptionFilter
그럼에도 기본 예외 처리 필터에게 넘기고 싶은 경우 보면 되는 녀석입니다

얘는 클래스입니다
추상 클래스라 부를 수 있는 정도의 녀석이구요

이 녀석을 상속 받아서 catch를 override한 다음 super.catch()로 넘기면 기본 예외 처리 필터가 처리를 해줍니다

### DI

## 전역으로 사용
main.ts로 가보시면 됩니다
useGlobalFilters에 new로 생성해서 바로 넣어주시면 되구요

```TypeScript
import { NestFactory } from "@nestjs/core";
import { AppModule } from "./app.module.ts";
import { TestFilter } from "./filters/test.filter.ts";

async function bootstrap() {
	const app = await NestFactory.create(AppModule);
	
	app.useGlobalFilters(
		new TestFilter()
	);
	
	await app.listen(process.env["PORT"] ?? 3000);
}

void bootstrap();
```
