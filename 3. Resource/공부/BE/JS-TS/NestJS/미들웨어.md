얘네가 Express에 기반을 둔 만큼 [[3. Resource/공부/BE/용어/미들웨어|미들웨어]]도 기본적으로는 똑같습니다

Express 공식 문서에 따르면 미들웨어는 다음과 같은 동작을 할 수 있다고 나와 있구요
- 어떤 형태의 코드라도 수행할 수 있다.
- 요청과 응답에 변형을 가할 수 있다.
- 요청/응답 주기를 끝낼 수 있다.
- 여러 개의 미들웨어를 사용한다면 `next()`로 호출 스택 상 다음 미들웨어에 제어권을 전달한다.

요청/응답 주기를 끝낼 수 있다는게 도대체 무슨 소리일까요

요청 안 넘기고 가만히 있으면 이 주기가 안 끝나잖아요
마찬가지로 예외 처리 안 해도 그렇구요

또는 현재의 미들웨어가 응답/예외 처리를 끝내지 않을 것이면서 next를 호출하지 않고 있으면 그 미들웨어에서 계속 루프를 돌 것이구요
어플리케이션이 멈추게 되겠죠

# 사용
얘는 UseMiddlewares 같은 것이 존재하지 않습니다
대신 모듈에 달거나 전역으로 달거나 두 가지의 경우밖에 없구요
전역은 그 와중에 함수로 만들어야 가능하기 때문에 클래스형 미들웨어는 여기에서 다시면 됩니다

```TypeScript
import { Module, NestModule, MiddlewareConsumer } from "@nestjs/common";
import { TestMiddleware } from "./middlewares/test.middleware.ts";

@Module(/* ... */)
class AppModule implements NestModule {
	configure(consumer:MiddlewareConsumer) {
		consumer.apply(TestMiddleware);
	}
}
```

## NestModule
```TypeScript
/**
 * @publicApi
 */
export interface NestModule {
    configure(consumer: MiddlewareConsumer): any;
}
```

아무 것도 없어요
any가 반환값인 이유로는 아마 return consumer.apply().forRoutes().apply()...를 위해서이지 않을까 싶네요

## MiddlewareConsumer
```TypeScript
/**
 * Interface defining method for applying user defined middleware to routes.
 *
 * @see [MiddlewareConsumer](https://docs.nestjs.com/middleware#middleware-consumer)
 *
 * @publicApi
 */
export interface MiddlewareConsumer {
    /**
     * @param {...(Type | Function)} middleware middleware class/function or array of classes/functions
     * to be attached to the passed routes.
     *
     * @returns {MiddlewareConfigProxy}
     */
    apply(...middleware: (Type<any> | Function)[]): MiddlewareConfigProxy;
}
```

체이닝으로 계속해서 연결할 수 있습니다
지금 보니 함수형 미들웨어도 여기에 꽂을 수는 있는 것 같네요
DI하기 힘들어서 그렇지

MiddlewareConfigProxy는 이렇게 생겼습니다
```TypeScript
/**
 * @publicApi
 */
export interface MiddlewareConfigProxy {
    /**
     * Routes to exclude from the current middleware.
     *
     * A route given with a `version` is only excluded for the requests for that
     * version: with URI versioning, through the version segment of its path,
     * and with header, media type or custom versioning, by the version the
     * request asks for.
     *
     * @param {(string | RouteInfo)[]} routes
     * @returns {MiddlewareConfigProxy}
     */
    exclude(...routes: (string | RouteInfo)[]): MiddlewareConfigProxy;
    /**
     * Attaches either routes or controllers to the current middleware.
     * If you pass a controller class, Nest will attach the current middleware to every path
     * defined within it.
     *
     * @param {(string | Type | RouteInfo)[]} routes
     * @returns {MiddlewareConsumer}
     */
    forRoutes(...routes: (string | Type<any> | RouteInfo)[]): MiddlewareConsumer;
}
```

	app.use(testMiddleware);
	
	await app.listen(process.env["PORT"] ?? 3000);
}
