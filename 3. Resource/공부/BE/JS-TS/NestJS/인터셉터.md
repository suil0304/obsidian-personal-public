라우트 핸들러가 실행되기 전/실행된 후의 요청/응답을 가로채어 자기가 원하는 대로 개-조할 수 있는 컴포넌트입니다

# 언제 실행되는가?
Guard로 체크한 후 Interceptor로 오게 됩니다

당연히 Request가 Controller에 닿았기 때문에 ExecutionContext를 제공 받구요

Middleware에서 1차적인 전처리를 수행했다면
여기에서 2차적인 전처리를 수행할 수 있습니다
좋잖아요

잘 처리하고 나면 이 데이터는 callHandler.handle()로 [[파이프#언제 실행되는가?|파이프]]를 거쳐 [[라우트 핸들러|라우트 핸들러]]가 실행된 후 다시 Interceptor에서 처리하게 됩니다

# 실행 순서
의외로 직관적일 수도 있습니다

마찬가지로 전역 실행 후 컨트롤러 -> 라우트 순서대로 실행되는데

응답 때에는 빠져나가야 하기 때문에 라우트 -> 컨트롤러 -> 전역 순서대로 실행됩니다

이런 느낌인 거죠

```TypeScript
class GlobalInterceptor implements NestInterceptor {
	intercept(context:ExecutionContext, next:CallHandler):Observable<any> {
		return next.handle(); // handle로 다시 내려감
		// 이 handle이 반환되는 때는 ControllerInterceptor의 반환이 끝났을 때
	}
}

class ControllerInterceptor implements NestInterceptor {
	intercept(context:ExecutionContext, next:CallHandler):Observable<any> {
		return next.handle(); // handle로 다시 내려감
		// 이 handle이 반환되는 때는 RouterInterceptor의 반환이 끝났을 때
	}
}

class RouterInterceptor implements NestInterceptor {
	intercept(context:ExecutionContext, next:CallHandler):Observable<any> {
		return next.handle(); // handle로 라우트 핸들러 실행
		// 다시 올라갑시다
	}
}

// RouterInterceptor -> ControllerInterceptor -> GlobalInterceptor
```

재귀의 느낌이라고나 할 수 있으려나
스택 느낌

# NestInterceptor
인터셉터는 기본적으로 이 interface를 구현해야 합니다

NestInterceptor라 함은 이렇게 생겼습니다
```TypeScript
/**
 * Interface describing implementation of an interceptor.
 *
 * @see [Interceptors](https://docs.nestjs.com/interceptors)
 *
 * @publicApi
 */
export interface NestInterceptor<T = any, R = any> {
    /**
     * Method to implement a custom interceptor.
     *
     * @param context an `ExecutionContext` object providing methods to access the
     * route handler and class about to be invoked.
     * @param next a reference to the `CallHandler`, which provides access to an
     * `Observable` representing the response stream from the route handler.
     */
    intercept(context: ExecutionContext, next: CallHandler<T>): Observable<R> | Promise<Observable<R>>;
}
```

그래서 구현할 때는 이런 방식으로 구현하시면 됩니다
```TypeScript
import { Injectable, ExecutionContext, NestInterceptor, CallHandler } from "@nestjs/common";
import { Observable } from "rxjs";

@Injectable()
class TestInterceptor implements NestInterceptor {
	intercept(context:ExecutionContext, next:CallHandler):Observable<any> {
		return next.handle()
			/* 그리고 Observable 메서드를 호출하여 후처리 완성 */;
	}
}
```

# 사용
## UseInterceptors
class 또는 method에 붙일 수 있습니다
알만 하잖아요

## DI
providers에 넣은 후 UseInterceptors에 넣으시면 됩니다
좋죠

## 전역
main.ts로 가봅시다

```TypeScript
import { NestFactory } from "@nestjs/common";
import { AppModule } from "./app.module.ts";
import { TestInterceptor } from "./interceptors/test.interceptor.ts";

async function bootstrap() {
	const app = await NestFactory.create(AppModule);
	
	app.useGlobalInterceptors(
		new TestInterceptor()
	);
	
	await app.listen(process.env["PORT"] ?? 3000);
}
```
