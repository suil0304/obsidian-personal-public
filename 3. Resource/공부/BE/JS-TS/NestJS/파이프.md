# 직접 만드는 법?
```TypeScript
import { type PipeTransform, type ArgumentMetadata, Injectable} from "@nestjs/common";

@Injectable()
export class TestPipe implements PipeTransform {
	transform(value:any, metadata:ArgumentMetadata) {}
}
```

사실 Injectable은 직접 new로 생성할 것이라면 필요 없습니다
직접 new TestPipe(new ConfigService())로 가져오면 되거든요

하지만 클래스 자체를 넘기고 Pipe 자체에서 받는 DI를 원할하게 하고 싶다던가 그렇다면 Injectable은 무조건 붙이는 것이 좋겠네요

```TypeScript
import { type PipeTransform, type ArgumentMetadata, Injectable} from "@nestjs/common";
import { ConfigService } from "@nestjs/config";

@Injectable()
export class TestPipe implements PipeTransform {
	constructor(private readonly __configService:ConfigService) {}

	transform(value:any, metadata:ArgumentMetadata) {}
}
```

PipeTransform은 다음과 같이 이루어져 있구요
```TypeScript
/**
 * Interface describing implementation of a pipe.
 *
 * @see [Pipes](https://docs.nestjs.com/pipes)
 *
 * @publicApi
 */
export interface PipeTransform<T = any, R = any> {
    /**
     * Method to implement a custom pipe.  Called with two parameters
     *
     * @param value argument before it is received by route handler method
     * @param metadata contains metadata about the value
     */
    transform(value: T, metadata: ArgumentMetadata): R;
}
```

# 사용
## UsePipes
파이프를 new로 생성해서 직접 넣어주거나 @Injectable을 달고 NestJS가 DI해주길 기대하는 방식으로 둘 다 굴릴 수 있구요

## ParameterDecorator에 넣기
일부 ParameterDecorator는 파이프를 받을 수 있습니다
거기에 넣어도 되구요

## 전역으로
```TypeScript
// /src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module.js';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
    const app = await NestFactory.create(AppModule);

    app.useGlobalPipes(
        new ValidationPipe({
            transform: true,
            whitelist: true,
            forbidNonWhitelisted: true
        })
    );

    await app.listen(process.env.PORT ?? 3000);
}

await bootstrap();
```

이런 느낌
ValidationPipe는 사용하려면 class-validator와 class-transformer가 필수적이라고 했던가
아무튼
