# SetMetadata
*class / method decorator*

메타데이터를 설정합니다
말 그대로에요

```TypeScript
export type CustomDecorator<TKey = string> = MethodDecorator & ClassDecorator & {
    KEY: TKey;
};
/**
 * Decorator that assigns metadata to the class/function using the
 * specified `key`.
 *
 * Requires two parameters:
 * - `key` - a value defining the key under which the metadata is stored
 * - `value` - metadata to be associated with `key`
 *
 * This metadata can be reflected using the `Reflector` class.
 *
 * Example: `@SetMetadata('roles', ['admin'])`
 *
 * @see [Reflection](https://docs.nestjs.com/fundamentals/execution-context#reflection-and-metadata)
 *
 * @publicApi
 */
export declare const SetMetadata: <K = string, V = any>(metadataKey: K, metadataValue: V) => CustomDecorator<K>;
```

무엇을 넣어도 상관은 없습니다

## Reflector.createDecorator
이것을 통해 만드시면 그 자체가 메타데이터를 설정하는 데코레이터가 됩니다

받고 저장하는 값은 제네릭으로 지정할 수 있습니다

```TypeScript
import { Reflector } from "@nestjs/core";

const Role = Reflector.createDecorator<string[]>();
```

이러면 Role은 string\[\]을 받아 저장하는 데코레이터가 되는 것입니다

옵션으로는 key와 transform을 넣을 수 있구요
알만 하잖아요

## reflector.get
특정 대상의 메타데이터를 가져옵니다

```TypeScript
import { Injectable, CanActivate, ExcutionContext } from "@nestjs/common";
import { Reflector } from "@nestjs/core";

@Injectable()
class TestGuard implements CanActivate {
	constructor(
		private readonly __reflector:Reflector
	) {}
	
	canActivate(context:ExcutionContext):boolean {
		const httpContext = context.switchToHttp();
		return this.__validateRequest(httpContext.getRequest(), context.getHandler());
	}
	
	__validateRequest(request:any, handler:Function) {
		const roles = this.__reflector.get(
			"roles",
			handler
		);
		
		return roles.includes(request["role"]);
	}
}
```

이런 식으로 handler에 붙어 있는 roles 메타데이터를 읽어서 Guard할 수 있다는 소리에요

"roles"는 Reflector.createDecorator로 만든 데코레이터로 대체 가능합니다

## reflector.getAll
여러 대상의 메타데이터를 읽을 수 있습니다
getAll에서 handler가 들어갔던 부분이 \[\]이라 생각하시면 됩니다

context.getClass와 context.getHandler에서 각각 가져오면 그 메타데이터는
```JSON
[
	["admin"],
	["user"]
]
```
가 되겠죠
