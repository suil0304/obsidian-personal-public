# 설정
끄고 키고
어디까지 출력할 것인지 지정하는 것부터 알아봅시다

main.ts 가보시면 NestFactory.create가 있을 텐데
그 뒤에 option을 먹일 수 있구요

option 중에 logger 필드가 있는데 false로 설정하시면 로그가 출력되지 않습니다

```TypeScript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module.js';
  
async function bootstrap() {
    const app = await NestFactory.create(AppModule, {
	    logger: false
    });

    await app.listen(process.env.PORT ?? 3000);
}

await bootstrap();
```

레벨 지정도 가능합니다

```TypeScript
const app = await NestFactory.create(AppModule, {
    logger: ["error", "warn", "log"] // 또는 "log"
});
```

# 사용
@nestjs/common에 보시면 Logger라는 녀석이 있습니다
DI를 받든 무엇을 하든 그것은 자유입니다

오히려 DI 없이도 사용할 수 있도록 설계된 녀석이라고 하네요

DI를 하지 않고 직접 생성하는 것을 더 권장하고 있다고도 하구요
커스텀 로거로 대체할 때 등 특수 상황이면 DI가 맞습니다
당연하죠

# 커스텀 로거
구현하고 싶다면 @nestjs/common의 LoggerService interface를 구현하시면 됩니다
근데 이러면 처음부터 구성해야 하구요

ConsoleLogger를 상속 받아 사용하게 할 수도 있습니다

## 전역으로 커스텀 로거 사용
main.ts에 가셔서 app.useLogger(app.get(MyLogger));하시면 됩니다

부트스트래핑 과정에서도 커스텀 로거를 사용해줍니다
