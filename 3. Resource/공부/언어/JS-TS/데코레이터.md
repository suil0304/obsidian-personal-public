데코레이터는 2개의 버전으로 나뉠 수 있습니다
그렇다네요
JS 표준으로 들어오면서 TS도 받아 들인 것을 그 동안 전혀 모르고 있었음

# 구버전 (TS Decorator)
총 5가지입니다
tsconfig.json에서 compilerOptions.experimentalDecorators를 사용 설정해야 사용할 수 있구요

## class
클래스를 꾸밀 수 있습니다
믹스인 형태로 사용할 수 있는 것 같은데요

```TypeScript
function ClassDecorator<ClassType extends { new (...args:any[]):any }>(Class:ClassType) {
    return class extends Class {
        readonly testThing:string = "sick";
    };
}

@ClassDecorator
class Class {}
```

## method
메서드는 기본이죠

안타깝게도 함수에는 데코레이터 적용이 안 되는 것 같습니다
\*crys\* why...
*호이스팅 문제라고는 하네요
이러언*

```TypeScript
function MethodDecorator(target:any, propertyKey:string, descriptor:PropertyDescriptor) {
    console.log(target);
    console.log(propertyKey);
    console.log(descriptor);

    const originalMethod = descriptor.value;

    descriptor.value = function() {
        console.log("method called");
        originalMethod?.();
    };
}

class Test {
    @MethodDecorator
    testFunc() {}
}
```

## accessor
접근자에도 저것을 걸 수 있네요
여기에서 접근자라 함은 gettter(get), setter(set)입니다
기본적으로 함수처럼 동작하니까요

## property
구버전은 PropertyDecorator의 반환값이 void 또는 any여야 한다고 하네요

```TypeScript
function PropertyDecorator(target:any, propertyKey:string):void {
    console.log("아이구 잘했어요");
}

class Test {
    @PropertyDecorator
    property:string;
}
```

## parameter
매개변수에도 달 수는 있습니다

```TypeScript
function ParameterDecorator(target:any, propertyKey:string, parameterIndex:number) {
    console.log("매개변수 꾸며짐");
}

class Test {
    testMethod(@ParameterDecorator sick:string) {
        console.log(sick);
    }
}
```

응용하면 검증도 가능은 하겠네요

```TypeScript
function ParameterDecorator(target:any, propertyKey:string, parameterIndex:number) {
    target.validator = function(sick:string) {
        if(sick != "sick") {
            throw new Error("너는 안 아프구나");
        }
    };
}

function MethodDecorator(target:any, propertyKey:string, descriptor:PropertyDescriptor) {
    const method = descriptor.value;

    descriptor.value = function(...args:any[]) {
        target.validator(args[0]);
        method?.(...args);
    };
}

class Test {
    @MethodDecorator
    testMethod(@ParameterDecorator sick:string) {
        console.log(sick);
    }
}

const test = new Test();
test.testMethod("sick");
```

제가 귀찮아서 validator 한 개만 해두고 순회하면서 검증하지도 않게 해뒀지만
아무튼 이런 것이 가능할 것 같아요

# 신버전
`(value:any, context:DecoratorContext)` 형태로 통합되었습니다
매개변수 데코레이터는 완전히 제거되었구요

DecoratorContext는 또 이를 자세히 구현하는 세부 DecoratorContext가 있어서 전용 데코레이터를 만들 수 있구요
DecoratorContext.kind로 알아서 switch문으로 대응하는 데코레이터를 만들 수도 있습니다

interesting

## class
```TypeScript
function Decorator(value:any, context:ClassDecoratorContext) {
    console.log("Test");
}

@Decorator
class Test {}
```

또는 위의 예시처럼 대체하는 것도 가능합니다

## method
```TypeScript
function Decorator(value:() => void, context:ClassMethodDecoratorContext) {
    console.log("Test");

    return function() {
        console.log("called");
        value();
    };
}

class Test {
    @Decorator
    method() {}
}
```

매우 직관적입니다

## property
```TypeScript
function Decorator(value:undefined, context:ClassFieldDecoratorContext) {
    console.log("꾸며지는 중");

    return function(initialValue:string) {
        console.log("초기화됨");
        return initialValue.toUpperCase();
    };
}

class Test {
    @Decorator
    property:string = "test";
}
```

초기화 시점에 어떻게 초기화할 것인가를 함수로 뱉을 수 있습니다

## accessor
```TypeScript
function GetterDecorator(value:() => string, context:ClassGetterDecoratorContext) {
    return function(this:any) {
        console.log("property 가져오는 중");
        return value.call(this);
    };
}

function SetterDecorator(value:(value:string) => void, context:ClassSetterDecoratorContext) {
    return function(this:any, str:string) {
        console.log("property 설정하는 중");
        value.call(this, str);
    }
}

class Test {
    private __property:string = "test";

    @GetterDecorator
    get property():string {
        return this.__property;
    }

    @SetterDecorator
    set property(value:string) {
        this.__property = value;
    }
}
```

상당히 직관적입니다

## auto-accessor
얘는 있는지도 몰랐습니다
`access`라는 키워드가 있었다네요
흐음

```TypeScript
function Decorator<This, Value>(
    value:ClassAccessorDecoratorTarget<This, Value>,
    context:ClassAccessorDecoratorContext
):ClassAccessorDecoratorResult<This, Value> {
    return {
        get() {
            console.log("값 가져오고 있음");
            return value.get.call(this);
        },
        set(newValue:Value) {
            console.log("값 설정하고 있음");
            value.set.call(this, newValue);
        },
        init(initialValue:Value) {
            console.log("값 초기화됨");
            return initialValue;
        }
    };
}

class Test {
    @Decorator
    accessor property:string = "sick";
}
```

이렇게 전부 외부에서 삽입할 수도 있습니다
