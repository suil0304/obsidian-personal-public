# 생각 / 느낌
당장에 obsidian-personal-public도 이 책으로 직접 구성한 것이니 만큼 엄청나게 효과적인 방법들을 배울 수 있었다는 사실이 가장 만족스러웠다. Notion에 불편함을 느껴 Obsidian으로 넘어온 것도 제법 있었는데, 만족할 만한 노트 앱임을 더욱 확실히 느낄 수 있었다. 추가로 노트를 어떻게 효과적으로 관리할 수 있을지에 관한 생산성 프레임워크 2개를 같이 소개해주어 적용해 보았는데(PARA, 제텔카스텐), 습관에 들 정도로 익숙해진다면 더 효율적이게 구성할 수 있을 듯 하여 앞으로의 내 길을 바꾸지 않았는가 하는 생각도 들 지경이다.
